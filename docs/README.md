# Plain Week documentation

Plain Week is a minimal, offline-first weekly planner. It is free, MIT licensed and self-hostable.

| Document                             | What it covers                                                       |
| ------------------------------------ | -------------------------------------------------------------------- |
| [stack.md](./stack.md)               | Versions, commands, folder layout, shadcn, Wayfinder, Inertia        |
| [style.md](./style.md)               | Visual style: the shadcn preset, tokens, dark mode, RTL, task colors |
| [architecture.md](./architecture.md) | The offline-first principle and the sync contract (canonical)        |
| [conventions.md](./conventions.md)   | Code style, naming, tests, commits and pull requests                 |

Contributors and coding agents should also read [AGENTS.md](../AGENTS.md) at the repository root.

Keep these documents current: when a change adds or alters a command, a convention, a design token or part of the
sync contract, update the matching document in the same pull request.
